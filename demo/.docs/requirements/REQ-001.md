# REQ-001: Gestor de notas CLI con persistencia local

`src/notas.py` debe permitir añadir, listar y marcar como hechas notas,
persistiéndolas en un archivo JSON junto al script (`notas.json`). La
salida debe ser texto plano legible, sin dependencias externas.
