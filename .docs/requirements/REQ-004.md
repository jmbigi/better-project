# REQ-004: Acceso de agentes al ecosistema via MCP

`scripts/mcp_server.py` expone un servidor MCP (stdio) con las herramientas:

- `search_knowledge(query, k)`: busqueda en la base de conocimiento.
- `read_requirement(id)`: lee una especificacion REQ-XXX.
- `validate_requirements()`: ejecuta la validacion de trazabilidad.
- `create_lesson(...)`: anade una leccion al YAML del anio en curso.

`opencode.json` lo lanza al iniciar el agente (clave `mcp`). El servidor es
stdlib puro: funciona sin dependencias externas y sin salida de red.
