# REQ-001: Trazabilidad de requisitos entre codigo y documentacion

El proyecto mantiene una base de datos de requisitos en `.docs/requirements/`,
con un archivo Markdown `REQ-XXX.md` por requisito y frontmatter YAML con los
campos: `id`, `titulo`, `estado` (Draft, Aprobado, Implementado, Deprecado),
`prioridad`, `version`, `fecha_creacion`.

El codigo que implementa un requisito debe llevar una referencia `// REQ-XXX`
(o `# REQ-XXX`) en el encabezado de la funcion/clase.

`scripts/doc_validator.py` verifica: que toda referencia en codigo tenga su
archivo, que el frontmatter sea valido, y que el estado sea coherente con el
uso en codigo. Devuelve exit 1 ante errores; con `--strict` tambien ante
advertencias. Se integra como hook de pre-commit.
