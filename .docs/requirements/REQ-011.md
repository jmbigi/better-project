# REQ-011: Cliente Jev AI liviano con llama.cpp

El proyecto incorpora conceptos Jev AI (System One: decisiones tipadas con
probabilidades calibradas, sin generar texto) de forma open source y gratuita.

Se implementa un script nativo Python (`scripts/jev_llama.py`) que usa
`llama-cpp-python` para cargar un modelo GGUF pequeño (~3–6 GB) y responder
preguntas tipadas: `noul` (yes/no), `choice` (elección múltiple) y `score`
(escala ordinal).

## Criterios de aceptacion

1. `scripts/jev_llama.py` carga un modelo GGUF desde `JEV_MODEL_PATH` y
   responde decisiones tipadas leyendo logits, sin samplear tokens.
2. Soporta los tres tipos de pregunta Jev: `noul`, `choice`, `score`.
3. Devuelve probabilidades, confianza y decision normalizada, con formato
   compatible con la API de Jev.
4. Configurable por variables de entorno (`JEV_MODEL_PATH`, `JEV_N_CTX`,
   `JEV_N_THREADS`, `JEV_TIMEOUT`) con valores por defecto razonables.
5. Manejo de errores real: falla explicito si falta el modelo, la dependencia
   o la entrada es invalida (P1.26).
6. Helper opcional `scripts/download_jev_model.py` para descargar el modelo
   recomendado desde HuggingFace de forma idempotente.
7. Documentacion en `.docs/knowledge/ai/jev_llama.md` con conceptos, uso,
   requisitos de hardware y licencias.
8. Tests unitarios con mocks y tests de integracion opcionales si existe
   `JEV_MODEL_PATH`.
9. La dependencia `llama-cpp-python` se declara en `requirements-optional.txt`.
