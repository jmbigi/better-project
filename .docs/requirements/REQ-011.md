# REQ-011: Cliente MDT liviano con llama.cpp

El proyecto incorpora el enfoque de modelos de decisión tipados (MDT; en inglés
*typed decision models*, TyDM; clase System One: decisiones tipadas con
probabilidades calibradas, sin generar texto) de forma open source y gratuita.

Se implementa un script nativo Python (`scripts/tydm_llama.py`) que usa
`llama-cpp-python` para cargar un modelo GGUF pequeño (~3–6 GB) y responder
preguntas tipadas: `noul` (yes/no), `choice` (elección múltiple) y `score`
(escala ordinal).

## Criterios de aceptacion

1. `scripts/tydm_llama.py` carga un modelo GGUF desde `TYDM_MODEL_PATH` y
   responde decisiones tipadas leyendo logits, sin samplear tokens.
2. Soporta los tres tipos de pregunta MDT: `noul`, `choice`, `score`.
3. Devuelve probabilidades, confianza y decision normalizada en formato JSON
   estable (estructura documentada en la seccion de tipos de decision).
4. Configurable por variables de entorno (`TYDM_MODEL_PATH`, `TYDM_N_CTX`,
   `TYDM_N_THREADS`, `TYDM_TIMEOUT`) con valores por defecto razonables.
5. Manejo de errores real: falla explicito si falta el modelo, la dependencia
   o la entrada es invalida (P1.26).
6. Helper opcional `scripts/download_tydm_model.py` para descargar el modelo
   recomendado desde HuggingFace de forma idempotente.
7. Documentacion en `.docs/knowledge/ai/tydm_llama.md` con conceptos, uso,
   requisitos de hardware y licencias.
8. Tests unitarios con mocks y tests de integracion opcionales si existe
   `TYDM_MODEL_PATH`.
9. La dependencia `llama-cpp-python` se declara en `requirements-optional.txt`.
