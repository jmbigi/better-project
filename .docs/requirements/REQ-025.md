# REQ-025: ADR Backfill automatizado

`scripts/adr_backfill.py` debe analizar el historial Git (`git log --grep`), las lecciones aprendidas (`.docs/lessons/`) y las rondas de pruebas (`docs/PRUEBAS.md`) para generar borradores de ADR retroactivos para decisiones clave tomadas implicitamente.

El script debe:
- Listar candidatos (`--list`)
- Previsualizar archivos a crear (`--dry-run`)
- Escribir borradores (`--write`) en `docs/decisions/ADR-NNN-titulo.md` usando la plantilla de `docs/decisions/PLANTILLA.md`

Cada borrador debe incluir todas las secciones obligatorias: Contexto, Alternativas consideradas, Decision, Consecuencias, Supuestos, Metricas de exito, Pre-mortem y Referencias.
