# REQ-023: ADRs obligatorios

## Contexto
El directorio `docs/decisions/` existe pero esta vacio (0 ADRs). Las decisiones arquitectonicas (perfiles deterministas, MCP local, allowlist/denylist, etc.) no estan documentadas. Esto dificulta la incorporacion de nuevos contribuidores y la auditoria.

## Criterios de aceptacion
- [ ] Regla en AGENTS.md: todo PR que toque arquitectura requiere ADR
- [ ] Plantilla ADR en `docs/decisions/template.md` (contexto, alternativas, decision, consecuencias, supuestos, metricas)
- [ ] ADR-0001 (proposito, REQ-021), ADR-0002 (perfiles deterministas), ADR-0003 (MCP local), ADR-0004 (bash allowlist/denylist) creados
- [ ] `adr_validator.py` verifica que cada cambio arquitectonico tenga ADR asociado
- [ ] Hook pre-commit o CI bloquea PRs sin ADR cuando tocan archivos de arquitectura

## Metrica de exito
1 ADR por decision arquitectonica. 0 decisiones sin ADR.

## Justificacion
La debilidad mas barata de arreglar y la mas valiosa para nuevos contribuidores. Sin ADRs, el conocimiento esta solo en cabezas y commits.
