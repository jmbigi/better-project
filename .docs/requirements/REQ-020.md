# REQ-020: Auditoria de cadena de suministro

> v1.0 (2026-09-20): implementa P0.18 con evidencia reproducible.

## Alcance

1. **Extras aislados**: `requirements-vector.txt` (busqueda vectorial, REQ-002)
   y `requirements-tydm.txt` (motor MDT, REQ-011); `requirements-optional.txt`
   los incluye con `-r`.
2. **Lock con hashes transitivos**: `requirements-optional.lock` generado con
   `uv pip compile --python-version 3.10 --generate-hashes`; instalacion con
   `--require-hashes`.
3. **Severidad real**: `scripts/audit_advisories.py` enriquece los advisories de
   `pip-audit --no-deps` con CVSS y alias via la API de OSV (urllib, sin
   dependencias); falla explicito si falta pip-audit o la red (P1.19).
4. **SBOM** desde el lock: `docs/SBOM-2026-09-20.cdx.json`.
5. **Auditoria opcional en CI**: `AUDIT=1 bash scripts/ci.sh`.

## Criterios de aceptacion

1. `pip-audit --no-deps -r requirements-optional.lock` resuelve y lista los
   advisories. **Cumplido**: 5 advisories (4 chromadb, 1 diskcache).
2. `python3 scripts/audit_advisories.py` emite la tabla con CVSS/CVE/GHSA.
   **Cumplido**.
3. `requirements-optional.lock` con hashes para todas las dependencias.
   **Cumplido** (117 paquetes, 3155 lineas).
4. Sin regresiones: suite y `verificar-proyecto.sh` en verde. **Cumplido**.

## Fuera de alcance

- Resolver los advisories (no hay version de parche publicada).
- syft v1.52.0, grype v0.119.0 y OpenSSF Scorecard v5.5.0 se instalaron
  localmente el 2026-09-25 (SHA256 verificado contra los releases oficiales,
  `.local/bin`, sin sudo; autorizados por el programador). grype escaneo el
  SBOM regenerado del arbol (sin `.local/`, `sbom/` ni venvs): 0 hallazgos.
  Scorecard no completa sin token de GitHub (rate limit anonimo de la API):
  pendiente de credencial del programador (P0.6).
- Firmas/procedencia SLSA >= 2 sin releases firmadas.
