# REQ-018: Fusion de candidatos de calibracion

> v1.0 (2026-09-19): cierra el flujo de ampliacion del set de calibracion
> (REQ-011) sin editar el JSON a mano.

`scripts/tydm_calibration_merge.py` fusiona de forma **idempotente** un fichero
de candidatos **aprobados por el programador** dentro del set validado, evitando
ids duplicados y subiendo la version. Por defecto es **dry-run** (no escribe);
con `--aplicar` modifica el set.

## Criterios de aceptacion

1. CLI `python3 scripts/tydm_calibration_merge.py [--set F] [--candidatos F]
   [--aplicar] [--forzar] [--json]`.
2. Sin `--aplicar` no modifica ningun archivo (dry-run, P1.9).
3. Rechaza ids duplicados respecto al set y respecto a los propios candidatos.
4. Exige que los candidatos esten en estado `aprobado` (o `aprobado_por_programador`)
   salvo `--forzar` (que queda como excepcion explicita).
5. Con `--aplicar`: agrega los casos, sube `version` y registra en
   `revision_humana` la fecha y los ids fusionados.
6. Tests: dry-run no escribe, fusion sube version, duplicado es error, estado no
   aprobado es error salvo `--forzar`.
7. No fusiona nada automaticamente sin orden humana (P1.15/P1.17).

## Fuera de alcance

- Revisar las etiquetas (lo hace `scripts/tydm_review.py --calibracion`).
- Re-ejecutar la calibracion (lo hace `scripts/tydm_calibration.py`).
