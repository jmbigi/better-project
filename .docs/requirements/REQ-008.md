# REQ-008: Script de onboarding (setup.sh)

`scripts/setup.sh` lleva al usuario desde la clonacion hasta la primera
validacion exitosa, sin instalar nada fuera del proyecto (P0.5).

## Criterios de aceptacion

1. Verifica el entorno: `python3` (>= 3.10), `git` y `bash` disponibles;
   informa con mensaje claro y codigo de salida 1 si falta algo (fail fast).
2. Instala el hook de pre-commit (`cp scripts/hooks/pre-commit
   .git/hooks/pre-commit`) de forma idempotente: si ya esta instalado e
   identico, lo indica y no toca nada (P1.34).
3. Pregunta (interactivo, con opcion `--yes` para no-interactivo) si se
   quieren las dependencias opcionales (chromadb, sentence-transformers) y,
   solo ante respuesta afirmativa, las instala en `.venv/` del proyecto.
   Nunca instala nada global ni sin confirmacion (P0.5, P1.23).
4. Genera el indice de conocimiento y termina ejecutando
   `bash scripts/verificar-proyecto.sh --pre-commit` como primera validacion.
5. `bash -n` limpio y verificado ejecutandolo en una copia temporal del repo.
