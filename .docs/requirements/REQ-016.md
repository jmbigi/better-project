# REQ-016: Revision humana asistida de clasificaciones Jev

> v1.0 (2026-09-19): UI de terminal (curses) que muestra las clasificaciones de
> `scripts/jev_pillars.py` (REQ-012) y recoge la confirmacion del programador
> (P1.15/P1.22). No aplica cambios a los documentos.

`scripts/jev_review.py` clasifica los pilares con el motor Jev y presenta cada
propuesta (con sus probabilidades y confianza) para que el programador la
acepte (`y`), la corrija (`n` + numero de opcion) o la salte (`s`). Guarda la
revision en un JSON generado; **no** modifica requisitos, lecciones ni
conocimiento (P1.17/P1.23).

## Criterios de aceptacion

1. Construye items de revision desde los pilares elegidos: `requisitos`
   (prioridad), `lecciones` (fase y categoria) y, opcional, `conocimiento`
   (relevancia).
2. Reutiliza `jev_pillars.ejecutar` (no duplica la logica de preguntas).
3. UI curses: muestra item, campo, propuesta, confianza y opciones; teclas
   `y`/`n`/`s`/`q`; al corregir, elige la opcion por numero.
4. Modo `--report`: imprime la tabla por consola (util sin TTY).
5. `--fake` usa un cliente simulado (sin cargar el modelo) para demo/tests.
6. Guarda `{fecha, total, ok, corregir, saltar, pendiente, filas}` en
   `.docs/.storage/jev_review.json` (generado, no versionado).
7. No escribe en `.docs/requirements/`, `.docs/lessons/` ni
   `.docs/knowledge/` (P1.17).
8. Tests unitarios de construccion de items, clasificacion con cliente
   simulado, aplicacion de decisiones y guardado, en
   `tests/test_ecosistema.py`.
9. Modo `--calibracion`: revisa las etiquetas de los **candidatos**
   (`.docs/knowledge/ai/jev_calibration_candidates.json`) sin cargar el modelo;
   el set validado no se modifica hasta que el humano apruebe y fusione.
10. Cachea las clasificaciones (`.docs/.storage/jev_review_cache.json`) y guarda
    el progreso de forma incremental (no se pierde por un timeout).

## Fuera de alcance

- Aplicar automaticamente las correcciones a los documentos (accion humana).
- Fusionar automaticamente los candidatos con el set validado (accion humana
  tras la revision; P1.15).
