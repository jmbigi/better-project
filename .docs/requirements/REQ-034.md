# REQ-034: Cobertura de lint sobre el proyecto demo

> v1.0 (2026-10-05): una evaluación externa del proyecto detectó que el check
> de lint del verificador (`ruff check scripts tests`) no cubría `demo/src`, y
> que allí existía un fallo real: F841 (variable `p_list` asignada sin usar) en
> `demo/src/notas.py:83`. Una verificación cuyo alcance es menor que el repo
> normaliza fallos fuera del foco y degrada la confianza en el resto de checks
> (P0.1: lo no verificado no es éxito).

## Objetivo

Que el lint del verificador cubra todo el código Python versionado del repo:
`scripts/`, `tests/` y `demo/src/`, con paridad entre `verificar-proyecto.sh`
y `verificar_proyecto.py` (la paridad es un invariante ya exigido por el
propio verificador).

## Criterios de aceptación

1. `ruff check scripts tests demo/src` termina con 0 errores.
2. `verificar-proyecto.sh` y `verificar_proyecto.py` ejecutan ruff con el
   mismo alcance.
3. El fallo F841 de `demo/src/notas.py` está corregido en origen (no
   silenciado con noqa ni exclusiones en `ruff.toml`).

## Trazabilidad

- Implementación: `scripts/verificar-proyecto.sh` (check_ruff),
  `scripts/verificar_proyecto.py` (check ruff equivalente),
  `demo/src/notas.py` (corrección F841).
- Lección relacionada: ver `.docs/lessons/2026.yaml` (alcance de checks =
  todo el repo o exclusión explícita justificada).
