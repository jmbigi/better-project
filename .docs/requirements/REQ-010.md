# REQ-010: Tests del propio verificador (verificar-proyecto.sh)

`verificar-proyecto.sh` es el componente mas critico del repo y hasta ahora
su unica red era ejecutarlo a mano. La suite lo prueba en modo fallo (P1.1:
un test que no puede fallar no es un test).

## Criterios de aceptacion

1. Test que ejecuta `verificar-proyecto.sh --pre-commit` sobre una copia
   temporal INTACTA del repo y exige codigo de salida 0.
2. Test que corrompe la copia (elimina una regla P0 de `AGENTS.md`) y exige
   codigo de salida 1 y el `[FALLO]` del check correspondiente.
3. Reutiliza la guarda anti-recursion `BETTER_TEST_INTEGRACION` para que la
   suite anidada dentro de la copia omita los tests de integracion.
4. Los tests son hermeticos: operan solo en directorios temporales.
