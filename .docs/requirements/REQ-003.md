# REQ-003: Repositorio de lecciones aprendidas

Las lecciones aprendidas se registran en `.docs/lessons/<anio>.yaml` con los
campos: `id` (LSN-NNN), `proyecto`, `fase`, `categoria`, `problema`,
`recomendacion`, `estado` (Abierta, Resuelta, Descartada), `fecha`.

`scripts/lessons_extractor.py` valida el formato y genera
`lessons_context.txt`, un archivo plano que los agentes leen de un plumazo
(sin parsear YAML). `--check` valida sin generar; `--json` exporta.
