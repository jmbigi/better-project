## Contexto
No hay KPIs medibles del proyecto como sistema. No se sabe si se mejora o empeora. Se necesitan 5 KPIs basicos publicados en cada CI.

## Criterios de aceptacion
- [x] `docs/health.md` generado automaticamente en CI con 5 KPIs:
  1. Tiempo de onboarding (minutos desde clone hasta `verificar-proyecto.sh` verde)
  2. % REQs trazados (Implementados con refs / total no Deprecados)
  3. Mutation score global (ponderado)
  4. Tiempo CI completo (segundos)
  5. Coste mantenimiento (% tiempo en tooling vs producto)
- [x] CI publica el dashboard como artifact o en `docs/health.md` versionado
- [x] Metas numericas definidas para cada KPI
- [x] Tendencia historica visible (ultimos 10 runs)

## Metrica de exito
Dashboard actualizado en cada CI. 5 KPIs con valor actual, meta y tendencia.

## Justificacion
Lo que no se mide, no se mejora. Hoy no hay KPIs del proyecto como sistema.
