# REQ-002: Indice de conocimiento local para busqueda semantica

El conocimiento del proyecto vive en `.docs/knowledge/` como Markdown
estructurado (una idea principal por seccion H2). `scripts/index_knowledge.py`
divide por H2, genera chunks y los indexa en `.docs/.storage/`.

Backends: ChromaDB + sentence-transformers (`all-MiniLM-L6-v2`, todo local) si
estan instalados; si no, indice JSON TF-IDF sin dependencias. El indizado es
incremental: solo re-indexa archivos modificados (manifest de mtimes).

`.docs/.storage/` no se versiona: se regenera con
`python scripts/index_knowledge.py`.
