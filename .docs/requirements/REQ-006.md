# REQ-006: Interfaz TUI minimalista para el ecosistema

Terminal UI (`scripts/tui.py`) con curses (stdlib, sin dependencias) para
operar el ecosistema sin salir del terminal: requisitos, conocimiento,
lecciones y verificacion.

## Vistas

1. **Requisitos**: lista de REQ con estado y prioridad, resumen de
   validacion de trazabilidad, detalle del archivo completo.
2. **Conocimiento**: busqueda sobre el indice (JSON TF-IDF o ChromaDB) con
   resultados y preview; accion de re-indexado.
3. **Lecciones**: lista de lecciones con estado y categoria, detalle con
   problema y recomendacion.
4. **Verificar**: salida de `verificar-proyecto.sh` con scroll y re-ejecucion.

## UX

- Minimalista: cabecera con titulo, barra de pestañas (1-4), area de
  contenido con scroll y barra de estado con atajos.
- Navegacion por teclado: `1-4` pestañas, `j/k` o flechas mover, `Enter`
  detalle, `Esc` volver, `q` salir (en detalle `q` vuelve).
- Colores solo si el terminal los soporta; degradacion sin color.
- Texto truncado y envoltura para terminales pequenos.
